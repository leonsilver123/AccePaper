# Agent Note: 修改请求由候选稿回答,而候选稿先被检查再被相信

Status: implemented

[English](2026-09-17-a-request-is-answered-by-a-candidate.md) | 中文

## 问题

人工门上的修改请求记录了一条要求,然后把闸门留在原处。系统里没有任何东西回答它。本该回答它的工作 —— 重写那个人抱怨的章节、检查重写有没有引入这篇研究没有的东西、把两者都摆给那个人看 —— 发生在产品之外,在 某个聊天或编辑器里,而这次运行从不知道有人向它提过要求。那条要求是持久的,而且是孤零零的。

## 决定

**请求成为一个对象,候选稿回答它,检查来评判这份候选稿。**

- **决定启动这个闭环。** 审批端点接受一个 hook,由服务实现:一条已生效的 `request_changes` 决定会记录 一条 `RevisionRequestRecord`,列出稿件的每个章节及其当时的正文哈希,以及这条要求针对哪些章节。hook 会被 await(所以"决定完立刻读闭环"的调用者能看到这条请求),而它的失败不能改变答案 —— 在它运行之前,决定已经 生效并落盘。
- **请求是有范围的。** 它带着写作者应当重写的章节;稿件其余部分原样带进候选稿,因为"把结果一节的论断收紧" 不是重写整篇论文的许可。
- **候选稿是**对着请求读到的那个版本**写的。** 基准在写入时**重新读出**:如果稿件自那个人读过之后移动过 —— 另一次修订、一次回滚、一次重新排版 —— 会被拒绝,而不是被"回答一份没人拥有的文档"的文字替换。请求 指向一个稿件已经没有的章节会被拒绝,写作者对某个章节什么都没写也会被拒绝。
- **写作者是部署自己的 prose 通道**,也就是 D3 与 D4 写作时用的那道缝,所以候选稿带着与它所修订的稿件 同样的来源标注,而且这个来源记在候选稿上,不靠假定。
- **检查读的是这次运行,不是被测文本。** 被改动章节里的数字必须是这次运行声明过或测量到的数字;它的引用 标号必须在稿件的参考文献表里;候选稿的章节必须与稿件完全一致。从被测文本本身取期望的检查,文本说什么 它就通过什么。
- **每条记录都是持久的、绑定版本的。** 请求、它的候选稿与它们的复核都放在部署的快照根下 (`revisions/<requestId>/`),用"写临时文件再改名"写入,而复核会写明它评判的候选稿哈希。重启后读到的是 同一个闭环;没看到过那次决定的页面,也仍然显示要求了什么、什么回答了它、检查说了什么。
- **页面不提供的那个操作是"接受",而且它直说。** 把候选稿变成正式稿件需要模块设计里描述的那次**接受事务** —— 版本比对、引用校验、对登记表的原子写入、下游失效 —— 并且要是核心操作、有它自己的生产调用者。在它 存在之前,面板不提供这个控件,并在一个人会去找它的地方说明这个缺口,而不是把候选稿渲染成已被接受。

## 考虑过的替代方案

**让页面把闭环放在自己的状态里。** 不需要任何持久记录,代价是让这条请求变成某个标签页的事实:刷新之后, 有人要求修改的稿件上方是一张空面板,而那份回答随浏览器一起消失。

**每个请求都重写整篇稿件。** 实现更简单 —— 一次写作者调用、不需要目标章节 —— 而它产出的是同名不同文的 另一篇论文,每个章节的哈希都变了,于是任何早先的复核都无法与任何东西比对。

**相信写作者自报改了什么。** 候选稿可以自己报告它改了哪些章节、产出了哪些哈希。那样,一个嘴上说"什么都没 改"、实际重写了结果一节的写作者就会被相信,而这正是基准哈希存在的理由。

**在这个模块里、对着工件登记表直接接受候选稿。** `recordArtifact` 只在步骤处于 `in_progress` 的尝试里 写入,而 E1-format 在任何人读到论文之前就已经提交,所以这里的"接受"要么是在一份仍描述旧值的回执旁边做逐 slug 写入 —— 登记表与回执互相矛盾 —— 要么把某个步骤回滚到 `in_progress` 来给一份手写的稿件腾位置。两种 都在把这项研究报成它从未到达过的状态。接受被留出来,并作为缺口记录在案。

## 后果

- 人的要求打开的闭环现在有了持久形状:请求、候选稿、差异、复核 —— 每一个都绑定版本,每一个在重启后都读得到。
- **闭环没有合上。** 一份被复核过的候选稿无法成为正式稿件,所以"响应一条修改请求"仍然是产品做不完的活儿; 页面如实说明这一点,而不是暗示相反。
- Web 包多了第十个页签,它的内容全部读自后端;客户端多了四个 Remote 方法(`listRevisions`、 `requestRevision`、`generateCandidate`、`reviewCandidate`),它们的描述符和其他方法一样必须到达浏览器的 Remote assembly bundle。
