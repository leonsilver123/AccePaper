# Agent Note: 闸门读的是论文实际携带的东西 —— 它的 float,以及它的标题

Status: implemented

[English](2026-09-17-the-gate-reads-what-the-paper-carries.md) | 中文

## 问题

交付那篇论文的两处缺陷躲过了流水线所有的检查,因为没有任何检查看它们。

1. **六个没人引用的 float。** Figure 1、Figure 2、Table 1 与三条公式,稿件的任何一句话都没有点名其中任何一个。`red-citation` 查的是相反方向 —— 正文引了而没有任何 float 携带的标号 —— 于是一个没人引用的 float 是不可见的。
2. **一个声称了研究已否证之结论的标题。** 交付的标题是 `Raising Minimum Time-to-Collision in Three-Vehicle Platoons via V2V-Enabled Adaptive Inter-Vehicle Gap Control`,而它下面的稿件报告的是该量**下降了 38.2%**。闸门判定了各节,却从未读那个每个读者最先读的句子。

两者形状相同:规则是针对稿件的**正文**写的,而论文的标题与它的对象都在正文之外。

## 决定

- **`red-citation` 拒绝「稿件带着某个 float、而正文从未点名它」的草稿。** 带着一个 float 的草稿等于已经判定这个 float 属于这篇论文;而正文从未点名它,等于没有用上它。规则拿交给复核的名册(`floatLabels`)与各节点名过的标号对照,并点名它发现了什么。
- **`red-claim` 拒绝「标题断言的方向与测量相反」。** 标题是从**稿件工件**(而不是计划)读进复核的,于是中途被改写的标题按它实际说的受判。规则按声明的方向词表双向读取,而一个不声称任何方向的标题 —— `Inserting One Autonomous Vehicle Changes a Platoon Minimum Time-to-Collision`,即测量与主张相反时真相的样子 —— 通过。
- **流水线自己的产出两条都通过**,这是本单元的另一半:夹具正文现在会点名它携带的 float(结果节点名图与表,方法节点名它陈述的公式),于是出货运行与第二个任务装配出的稿件能活过它们本来会被拒绝的规则。
- **质量基线同时认识两种引用语法。** 草稿带 `[@citeKey]`,E1 印的是 `[1]`;只认后者的规则会把这次运行的引言报成「一句都没引」—— 对一篇引用了三个来源的论文报出两条缺陷。

## 考虑过的其他做法

- **把「没人引用的 float」报成 warning 而不是拒绝。** 拒绝:计划自己的核验表把它列为机器可判定,而交付论文就是「只报 warning」在四轮审计之后的样子。一个携带没人用的 float 的流水线应当停下,而不是加注释。
- **在 E1 而不是闸门检查标题。** 拒绝:闸门才是「对运行已经写出的稿件作判定」的地方,而标题是它的一句话。E1 已经拒绝了引用与论证义务。
- **从研究计划而不是工件读标题。** 拒绝:交付那次运行的标题来自模型路线,与计划的不同;判计划的标题等于判一句论文并不携带的话。
- **在闸门上也要求公式被引用。** 现在不做:公式是 E1 在闸门所审的各节之后追加到方法节的,闸门手里的名册看不到它们。基线看的是装配后的稿件并报告它们,那才是它该在的地方。

## 后果

- **两条拒绝都在生产路径上**,且在一次驱动的运行里都可达:写作者的文字不点名任何 float 会挡住 D3,而交付论文的那个标题会挡住 claim 角色。
- **出货运行与第二个任务的 `qualityFindings` 都是空的** —— 同一套基线此前会在这条流水线更早的产出上报出六个无人引用的对象与「没有文献位置」,现在在一个主张被否证的运行和一个主张被支持的运行上都什么也不报。
- **这里没有覆盖的。** 标题规则读的是方向词而不是含义:用声明词表之外的说法断言结论的标题会通过,而标题**好不好**需要读者。「没人引用的 float」这条覆盖闸门持有的名册 —— 图、表与路线图 —— 不覆盖公式,公式是 E1 在闸门运行之后追加的。
