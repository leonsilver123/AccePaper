# Agent Note:科研标签页说清自己是什么、怎么用、正文是谁写的

Status: implemented

[English](2026-09-15-research-tab-explains-itself.md) | 中文

## 问题

没读过设计文档的人**用不了**这个科研标签页。

浏览器驱动的页面上实测:本次改动之前,标签页渲染的是 `科研`、一个来源徽标、一个 `运行流水线` 按钮和九个标签页名。页面上没有任何东西说明一次运行会做什么、产物写到哪里、它会停在哪一步,也没有说明屏幕上的数字是**内置演示快照**而不是某次运行。用户的反馈就是:完全没看懂这个插件如何使用。

在回答第一个问题的过程中,查出了**第二个独立的缺陷**。wire 上带着每一步的 `kind` —— run 为该步记录的真值等级 —— 而视图只从中读了一个值(`fixture_executor`,用作降级标注)。于是一次手稿正文来自部署**确定性离线通道**的运行,被标成 `真实运行`、对正文只字不提,而这次运行导出的手稿开篇就写着"没有调用任何模型"。徽标与工件互相矛盾,而**夸大的是页面**。

## 决定

**工作台自己说明自己,且它的每一项主张都是推导出来的,不是写死的。**

每次渲染时,运行控件上方都有一块引导区,说明三件事:这条流水线是什么(一条主张走完 16 步、阶段 A–E,每一步只有通过 A/B/C 三一评判才前进,裁不出来的一步以 `弃审` 结束);怎么用(按运行;运行停在 E2-submit 人工门等裁决;产物与目录在「概览 → 落盘产物」);以及下一步做什么。

**"下一步"由 `panels.ts` 的 `selectNextAction` 从 summary 推导**,按"什么在挡住读者"排序:演示数据压过一切 —— 页面显示内置快照时,无论那份演示里是什么状态,都没有一次运行可供操作;失败的步骤压过人工等待 —— 因错误停下的运行不是一个人能批准的;人工等待压过仍在进行的步骤 —— 没有裁决,运行出不了那道门。

**写手稿正文的是哪个通道,按 run 自己的记录陈述。** `summary.ts` 的 `proseChannelOf` 读那些"产物就是手稿正文"的步骤(D2-framework、D3-writing、D4-rebuttal)的 `executionKind`,给出 `model` / `deterministic` / `fixture` / `unknown`。只要有一个 `live_external` 步骤,这次运行就是模型运行。步骤行携带 `executionKind`,来源是 wire 的 `kind` —— `run-source.ts` 现在**映射**它,而不是丢掉它。

运行之前,同一处说明当前页面显示的是内置演示快照、本次会话还没有启动过运行;运行之后,它改说通道。

## 考虑过的其他方案

**加第二个 Remote 方法向部署询问它的通道,好让页面在运行之前就能说出来。** 否决:该命名空间只有 `run` 一个 Remote 方法,加一个要走 Typert 生成器并重装 profile 才能发布。它同时也是**更弱**的来源 —— 配置里写的是部署**会**用什么,而 run 记录的是**真正跑了什么**;散文标注当初就是照这条区分,从 writer 上读 `channel`,而不是假设。

**把运行前的状态交给 `演示数据 (MOCK)` 徽标。** 否决:徽标说的是**屏幕上这些数字**从哪来,不是"什么都没跑过"。这是两件事,而后者才是一个人按下"驱动 16 步流水线并写文件"的按钮**之前**需要知道的。

**用面板自身的状态代替新增引导区。** 否决:面板展示**状态**,不陈述**流程**。还没开始的运行,没有任何面板能说出开始它会做什么。

**在浏览器探针里逐字断言引导文案。** 否决:客户端文案归 locale 所有,逐字断言等于把英文(或中文)文本钉进探针。组件发布 `data-research-intro`、`data-research-source-note`、`data-research-next-action` 三个属性,探针读它们,再检查文案**覆盖了**需求点到的那几件事。

## 后果

**"下一步"那一行是页面自己对运行状态的主张。** 它与面板渲染的是同一份 summary,所以不会与面板互相矛盾;但它只和记录的步骤状态一样准:某一步记录的状态错了,那一行会和那一行步骤一起错。它不陈述任何面板没有的东西。

**`proseChannelOf` 按 id 认识它的步骤。** 若某个构建重命名了 `D2-framework`、`D3-writing` 或 `D4-rebuttal`,它报 `unknown` —— "这个构建说不出来" —— 而不是报一个这次运行从未用过的通道。

**引导区不属于导出的工件。** 只读手稿的人仍然会在手稿里遇到那条演示声明;本次改动负责的是让他们在**开始之前**就知道。
