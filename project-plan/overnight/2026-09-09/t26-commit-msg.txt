feat (research-web): T26 — conversation.view slot + Mock run summary view

Add the browser half of the research plugin: a fixture-driven conversation
view tab rendering a typed run summary. The view loads an immutable fixture
and renders it through a React component, with a MOCK badge, 16-step
progress, artifact list, gate history, abstention freeze, and degradation
notes. The Host half is intentionally inert (the view is browser-only); its
exports are type-only re-exports of the RunSummary model so a future
T19-B adapter can hand a real snapshot to the same view.

Coverage

- 12 vitest tests in tests/summary.client.spec.ts cover the model
  (toRunSummary, buildSummary, fixture load), gate history & abstention
  shape, degradation notes, the 16 step statuses, humanPending derivation,
  and the adapter entry point.
- web lib (lib/index.js + lib/client.js) builds via tsdown; main entry
  smoke: 4 exports; client face is the browser bundle (window-bound).
- dsx-research-web surface stays consistent with other research packages
  (dual-face plugin: src/index.ts host inert; src/client/* browser half).

- tsconfig.client.json: declare packages/research/dsh-research-web/src
  /client/css-modules.d.ts and reference the web package in the client
  project graph (this is the same pattern other dsh-client-* packages use
  for their CSS modules).
- pnpm-lock.yaml: add the web importer and its 5 client-side workspace
  devDependencies (cordis + dsh-client-{locale,ui-conversation,ui-renderer,

  no other lock changes.
